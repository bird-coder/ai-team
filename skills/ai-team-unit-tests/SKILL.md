# AI Team Unit-test Acceptance

Read [the acceptance standard](references/acceptance.md) completely before using
this skill. It is the existing team standard, with its responsibilities, phase
limits and PASS/FAIL/BLOCKED/NOT_APPLICABLE semantics unchanged.

The parent supplies team_root and project_root. References in the standard to
design-review.md and the development workflow mean
team_root/workflows/design-review.md and team_root/workflows/development.md,
respectively; they are not paths inside this skill. Read them when the assigned
phase requires those rules.

Apply only the assigned responsibility; this skill does not authorize earlier
implementation or turn a test-planning assignment into code changes.
